초록 (Abstract)

극한 홍수 예측에서 첨두 유량을 낮게 예측하면 경보와 대응이 늦어질 수 있다. Multi-basin LSTM은 여러 유역의 수문 반응을 함께 학습할 수 있지만, deterministic output만 사용할 경우 큰 홍수 첨두를 과소추정하는 경향이 남는다. 본 연구는 이러한 한계가 LSTM backbone 자체만의 문제가 아니라, 하나의 중앙예측값만 내는 output design의 제약일 수 있다고 보았다.

이를 확인하기 위해 동일한 LSTM backbone을 유지한 채, 출력 head만 deterministic prediction에서 q50/q90/q95/q99 quantile output으로 확장한 probabilistic multi-basin LSTM을 구성하였다. Model 1은 deterministic LSTM baseline으로, Model 2는 quantile head를 가진 probabilistic extension으로 정의하였다. 두 모델은 fixed subset300 학습 조건에서 paired seed 111/222/444로 비교하였고, Results 분석은 expanded DRBC observed test split의 85개 basin, 2014–2016 test period를 canonical evaluation으로 사용하였다.

결과적으로 Model 2의 q50은 central prediction 성능을 유지하였다. Basin-median NSE는 Model 1의 −0.031에서 Model 2 q50의 0.225로 증가했으며(Δ = +0.149), RMSE와 MAE도 각각 −0.273, −0.197 개선되었다. 더 중요한 결과는 upper quantile에서 나타났다. Q99 exceedance event(82개 유역, 926개 사건)에서 q99의 event peak under-deficit(α)은 0.018까지 낮아졌고, Q99 threshold recall(δ)은 0.583까지 높아졌다. NOAA/NWS confirmed flood subset(21개 유역, 65개 사건)에서도 같은 방향의 개선이 확인되었다.

그러나 이 개선은 비용 없이 얻어진 것이 아니다. q99는 q50보다 high-flow recall을 약 8배 높였지만, false alarm rate(FAR)도 약 23배 증가시켰다. All-hour empirical one-sided coverage는 q99에서 0.787로 nominal 0.99에 미치지 못했다. 따라서 본 연구의 quantile output은 calibrated 99% predictive interval이나 return-period estimate가 아니라, 극한 첨두 과소추정을 줄이기 위한 upper-tail decision output으로 해석해야 한다.

본 연구는 deterministic LSTM의 극한 홍수 과소추정 문제가 일부는 output design에서 비롯될 수 있음을 보이며, 동일한 backbone에 probabilistic quantile head를 추가하는 것만으로도 flood peak protection 성능을 개선할 수 있음을 제시한다.

Keywords: Multi-basin LSTM, probabilistic streamflow forecasting, extreme flood underestimation, quantile regression, DRBC holdout, peak underestimation, uncertainty band

제 1장 서론

1.1 연구 배경

하천 유량 예측에서 평상시 유량을 잘 맞추는 것은 중요하지만, 실제 재난 대응과 홍수 경보에서는 드물게 발생하는 첨두유량을 놓치지 않는 것이 더 직접적인 안전 문제로 이어진다. 수문 예측 모델은 Nash-Sutcliffe Efficiency(NSE)와 같은 전체 기간 지표를 최적화하는 과정에서 자연스럽게 평상시 유량 조건에 더 많은 학습 용량을 할당하게 된다. 이 때문에 관측 빈도가 낮은 극한 홍수 사건에서는 모델이 첨두 크기를 낮게 예측하는 경향이 나타날 수 있다.

LSTM(Long Short-Term Memory) 기반 수문 예측 모델은 최근 여러 유역에 걸친 rainfall-runoff 관계를 동시에 학습하는 multi-basin 구조로 발전하였으며, 전통적인 물리 기반 모델 수준 이상의 예측 성능을 보여왔다(Kratzert et al., 2018, 2019). 그러나 하나의 deterministic 출력값만 생성하는 구조에서는 rare high-flow event에서 peak를 낮게 예측하는 경향이 여전히 남는다. 이는 training objective가 전체 시간의 bulk flow를 강하게 반영하고, 극단값은 빈도가 낮아 loss에서 충분히 강조되지 않기 때문이다.

본 연구는 이 문제를 "LSTM을 더 복잡하게 만들 것인가"가 아니라 "같은 backbone의 출력을 어떻게 설계할 것인가"의 문제로 다룬다. 즉 deterministic point estimate 하나만 출력하는 대신, 같은 시점에서 중앙예측과 여러 수준의 upper-tail output을 동시에 제공하면 extreme peak underestimation을 줄일 수 있는지 확인한다.

1.2 연구 목적과 가설

핵심 연구 질문: Multi-basin LSTM 기반 hourly streamflow 예측에서 probabilistic quantile head만 추가해도 deterministic baseline의 extreme flood peak underestimation을 줄일 수 있는가?

이를 위해 다음 가설을 검증한다.

  1. H1. Model 2의 q50은 Model 1 deterministic output과 비교 가능한 central prediction으로 기능해야 한다. (→ RQ-1)
  2. H2. q90/q95/q99는 τ가 커질수록 peak underestimation을 줄이는 방향으로 작동해야 한다. (→ RQ-2)
  3. H3. Peak underestimation 감소에는 false-positive 또는 over-prediction cost가 동반되므로, recall만이 아니라 cost도 함께 평가해야 한다. (→ RQ-3)
  4. H4. q99는 return-period flood나 양방향 prediction interval이 아니라 one-sided upper-tail decision output으로 해석해야 한다. (→ RQ-5)

1.3 연구 기여

  • 공정한 Model 1 vs Model 2 비교 구조: backbone, 입력 변수, basin split, temporal split, seed를 고정하고 output head와 loss만 바꾸어 probabilistic head의 효과를 분리하였다.
  • DRBC regional holdout 평가: non-DRBC basin에서 학습한 global multi-basin model을 DRBC basin에서 평가하여, spatial generalization 조건에서 peak underestimation을 분석하였다.
  • Quantile output 해석 framework 제시: q50은 central prediction, q90/q95/q99는 보수성 수준이 다른 upper-tail decision output으로 구분하고, calibration claim과 operational peak-capture claim을 분리하였다.

제 2장 이론적 배경

2.1 Multi-basin LSTM

LSTM(Long Short-Term Memory)은 vanishing gradient 문제를 cell state와 gating mechanism으로 극복한 recurrent neural network로, 강수·기온·복사 등 dynamic forcing의 시간적 의존성을 효과적으로 학습한다. 수문 예측에서는 과거 forcing sequence와 basin static attributes를 함께 사용해 basin별 rainfall-runoff response를 예측한다.

Multi-basin LSTM은 수백 개의 유역 데이터를 하나의 모델에서 함께 학습함으로써, 데이터가 부족한 개별 유역에서도 다른 유역의 패턴을 활용한 일반화 성능을 얻을 수 있다(Kratzert et al., 2019). 본 연구의 두 모델은 모두 같은 CudaLSTM backbone을 사용한다.

그림 1. Model 1 vs. Model 2 아키텍처 비교. 두 모델은 동일한 shared multi-basin CudaLSTM backbone(hidden size 128, 336h lookback)을 사용한다. 차이는 output head와 training objective뿐이다 — Model 1은 regression head + NSE loss, Model 2는 quantile head + pinball loss.
그림 2. 단일 336시간 시퀀스 입력-출력 구조. Dynamic inputs + static attributes를 336시간 lookback으로 소비하고, 마지막 시점에서 Model 1은 point estimate, Model 2는 q50/q90/q95/q99를 동시에 출력한다.

2.2 Model 1: Deterministic Baseline

Model 1은 매 시점 하나의 streamflow 값을 예측하는 deterministic regression model이다. 전체 hydrograph의 평균적 적합도를 잘 확보할 수 있지만, rare high-flow peak에서는 conditional mean 쪽으로 수축하면서 underestimation이 발생할 수 있다.

2.3 Model 2: Probabilistic Quantile Extension

Model 2는 Model 1과 같은 backbone을 사용하되, head만 quantile output으로 바꾼다. 출력 분위수 집합은 τ ∈ {0.50, 0.90, 0.95, 0.99}이다.

→ 그림 1 (Model 1 vs. Model 2 Architecture) 참조.

q50은 conditional median으로, Model 1 deterministic output과 가장 직접적으로 비교되는 central prediction이다. q90/q95/q99는 lower quantile이 없는 one-sided upper-tail output이다. 따라서 본 연구에서는 이를 prediction interval이나 return-period estimate로 해석하지 않는다. 특히 q99는 100-year flood가 아니라, 해당 시점 조건에서 모델이 내는 가장 보수적인 upper-tail decision output이다.

2.4 분위수 손실 함수 (Pinball Loss)

Model 2는 분위수별 pinball loss(Koenker & Bassett, 1978)를 사용하여 학습한다. 시각 \(t\)에서 관측 유량을 \(y_t\), 분위수 \(\tau\)에 대한 예측값을 \(\hat{y}_{t,\tau}\)라 할 때, 단일 시각의 pinball loss는 다음과 같이 정의된다.

\[ L_\tau(y_t,\, \hat{y}_{t,\tau}) = \begin{cases} \tau\,(y_t - \hat{y}_{t,\tau}) & \text{if } y_t \geq \hat{y}_{t,\tau} \\[4pt] (1-\tau)\,(\hat{y}_{t,\tau} - y_t) & \text{if } y_t < \hat{y}_{t,\tau} \end{cases} \tag{1} \]

분위수 집합 \(\mathcal{T} = \{0.50,\, 0.90,\, 0.95,\, 0.99\}\)에 대한 전체 학습 손실은 각 분위수의 손실을 균등 평균하여 정의한다.

\[ \mathcal{L}_{\text{pinball}} = \frac{1}{|\mathcal{T}|\,T} \sum_{\tau \in \mathcal{T}} \sum_{t=1}^{T} L_\tau(y_t,\, \hat{y}_{t,\tau}) \tag{2} \]

여기서 \(T\)는 학습 기간의 전체 시간스텝 수이다. \(\tau\)가 클수록 관측값이 예측값보다 큰 경우(under-prediction)에 더 큰 패널티가 부과된다. 이 비대칭 구조 덕분에 상위 분위수(q90, q95, q99)는 첨두 과소추정을 줄이는 방향으로 학습된다. 반면 Model 1은 표준 NSE 기반 평균제곱오차 손실을 사용한다.

2.5 평가 지표

본 연구는 전체 수문곡선 성능과 홍수 첨두 특화 성능을 분리하여 평가한다. 이하에서 공통 기호를 먼저 정의한다.

  • \(y_t\) : 시각 \(t\)에서의 관측 유량 [m³/s]
  • \(\hat{y}_t\) : 시각 \(t\)에서의 점 추정 예측값 (Model 1 단일 출력, 또는 Model 2 q50)
  • \(\hat{y}_{t,\tau}\) : 시각 \(t\)에서 분위수 \(\tau\)의 예측값 (Model 2)
  • \(\bar{y}\) : 평가 기간 관측 유량의 시간 평균
  • \(T\) : 평가 기간 전체 시간스텝 수
  • \(\mathbf{1}[\cdot]\) : 조건이 참이면 1, 거짓이면 0을 반환하는 지시 함수(indicator function)

2.5.1 전체 성능 지표

결정론적 예측(Model 1 및 Model 2의 q50)의 전반적 수문곡선 적합도를 평가하기 위해 수문학 분야에서 널리 사용되는 지표들을 활용한다.

Nash-Sutcliffe Efficiency (NSE) (Nash & Sutcliffe, 1970)

전체 수문곡선 형태의 적합도를 평가한다. 1에 가까울수록 완벽한 예측이며, 0은 관측 평균값으로 예측한 것과 동등한 성능, 음수는 그보다 나쁜 경우를 의미한다.

\[ \text{NSE} = 1 - \frac{\displaystyle\sum_{t=1}^{T}(y_t - \hat{y}_t)^2}{\displaystyle\sum_{t=1}^{T}(y_t - \bar{y})^2} \tag{3} \]

Kling-Gupta Efficiency (KGE) (Kling et al., 2012)

상관관계, 변동성 편향, 평균 편향을 동시에 분해하여 종합 평가한다. 1이 최적이며, NSE보다 고유량 조건에서 더 균형 잡힌 진단을 제공한다(Knoben et al., 2019).

\[ \text{KGE} = 1 - \sqrt{(r-1)^2 + \left(\frac{\sigma_{\hat{y}}}{\sigma_y}-1\right)^2 + \left(\frac{\mu_{\hat{y}}}{\mu_y}-1\right)^2} \tag{4} \]

여기서 \(r\)은 관측값과 예측값 간의 피어슨 상관계수, \(\sigma_{\hat{y}}/\sigma_y\)는 표준편차비(변동성), \(\mu_{\hat{y}}/\mu_y\)는 평균비(편향)를 나타낸다.

평균 절대오차 (MAE) 및 평균 제곱근 오차 (RMSE)

\[ \text{MAE} = \frac{1}{T}\sum_{t=1}^{T}\left|y_t - \hat{y}_t\right|, \qquad \text{RMSE} = \sqrt{\frac{1}{T}\sum_{t=1}^{T}(y_t - \hat{y}_t)^2} \tag{5} \]

두 지표 모두 단위는 m³/s이며, 0에 가까울수록 우수하다. RMSE는 이상치(outlier)에 민감하고 MAE는 선형적이므로, 두 지표를 함께 사용하면 오차 분포의 성격을 파악할 수 있다.

2.5.2 홍수 첨두 성능 지표

전체 기간 지표는 드물게 발생하는 극한 홍수 첨두에서의 성능을 충분히 반영하지 못한다. 본 연구는 Q99 초과 사건(event) 집합 \(E\)를 대상으로 다음 네 가지 첨두 특화 지표를 정의한다. \(Q_{99}^{(b)}\)는 유역 \(b\)의 관측 유량 99번째 백분위수이다.

첨두 과소추정 비율 \(\alpha\) (Peak Under-Deficit)

Q99 사건의 관측 첨두 시각에서 예측값이 얼마나 부족한지를 상대 비율로 측정한다. 0에 가까울수록 첨두를 잘 포착한 것이다.

\[ \alpha = \frac{1}{|E|}\sum_{e \in E} \frac{\max\!\left(0,\; y_e^{\text{peak}} - \hat{y}_{e,\tau}^{\text{peak}}\right)}{y_e^{\text{peak}}} \tag{6} \]

여기서 \(y_e^{\text{peak}}\)는 사건 \(e\)에서의 관측 첨두유량, \(\hat{y}_{e,\tau}^{\text{peak}}\)는 분위수 \(\tau\)의 예측 첨두유량이다.

±6시간 창 포착률 \(\beta\) (Window Capture Rate)

관측 첨두 발생 시각 기준 ±6시간 창 안에서 예측값이 관측 첨두 크기에 도달하는지 여부를 평가한다. 1에 가까울수록 우수하다.

\[ \beta = \frac{1}{|E|}\sum_{e \in E} \mathbf{1}\!\left[\max_{|k|\,\leq\,6}\hat{y}_{t_e+k,\,\tau} \;\geq\; y_e^{\text{peak}}\right] \tag{7} \]

여기서 \(t_e\)는 사건 \(e\)의 관측 첨두 발생 시각, \(k\)는 시간 오프셋(hour) 단위이다.

Q99 임계값 재현율 \(\delta\) (Q99 Threshold Recall)

관측값이 유역별 Q99 임계값을 초과하는 모든 시간스텝 중, 예측값도 Q99를 초과하는 비율이다. 홍수 경보 관점에서 1에 가까울수록 우수하다.

\[ \delta = \frac{\#\!\left\{t:\; y_t > Q_{99}^{(b)} \;\wedge\; \hat{y}_{t,\tau} > Q_{99}^{(b)}\right\}} {\#\!\left\{t:\; y_t > Q_{99}^{(b)}\right\}} \tag{8} \]

오경보율 FAR (False Alarm Rate)

예측이 Q99를 초과하였지만 실제 관측은 Q99 미만인 경우의 비율이다. 홍수 경보의 신뢰도 비용을 나타내며, 0에 가까울수록 우수하다.

\[ \text{FAR} = \frac{\#\!\left\{t:\; y_t \leq Q_{99}^{(b)} \;\wedge\; \hat{y}_{t,\tau} > Q_{99}^{(b)}\right\}} {\#\!\left\{t:\; \hat{y}_{t,\tau} > Q_{99}^{(b)}\right\}} \tag{9} \]

2.5.3 확률론적 보정 지표

Model 2가 출력하는 분위수 예측의 통계적 유효성은 경험적 피복률(empirical coverage)로 진단한다.

경험적 피복률 (Empirical Coverage)

실제 관측값이 분위수 \(\tau\) 예측값 이하에 놓이는 비율이다. 이상적으로 보정된 모델이라면 Coverage(\(\tau\)) ≈ \(\tau\)가 성립한다.

\[ \text{Coverage}(\tau) = \frac{1}{T}\sum_{t=1}^{T}\mathbf{1}\!\left[y_t \leq \hat{y}_{t,\tau}\right] \tag{10} \]

보정 오차(Calibration Error)는 명목 피복률 \(\tau\)와 경험적 피복률의 차이로 정의한다.

\[ \text{CE}(\tau) = \left|\,\text{Coverage}(\tau) - \tau\,\right| \tag{11} \]

\(\text{CE}(\tau) = 0\)이면 해당 분위수가 통계적으로 잘 보정되었음을 의미한다. 본 연구에서는 τ ∈ {0.90, 0.95, 0.99}에 대해 이 지표를 보고한다.

제 3장 데이터와 실험 방법

3.1 CAMELSH Hourly Dataset

본 연구는 CAMELSH(Catchment Attributes and MEteorology for Large-sample Studies — Hourly) hourly dataset을 사용한다(Tran et al., 2025). hourly 해상도는 daily dataset보다 빠른 flood response와 첨두 timing을 더 직접적으로 분석할 수 있는 장점이 있다.

Dynamic forcing에는 강수, 기온, 복사, 습도, 풍속 등 hourly meteorological variables를 사용하고, static attributes에는 area, slope, aridity, snow fraction, soil depth, permeability, forest fraction, baseflow index 등을 사용한다. Lagged observed streamflow는 본 비교축에 포함하지 않았다. 이는 deterministic baseline이 과도하게 강해져 probabilistic head의 순수 효과를 해석하기 어려워지는 것을 막기 위한 통제다.

3.2 DRBC Regional Holdout

Delaware River Basin Commission(DRBC) 경계는 본 연구의 regional holdout test region이다. DRBC holdout 정의는 outlet_in_drbc == True AND overlap_ratio ≥ 0.9 조건을 만족하는 154개 basin이다. 모델은 DRBC 내부 basin을 학습하지 않고, non-DRBC basin에서 global multi-basin model로 학습된다. 따라서 본 실험은 Delaware 전용 regional model이 아니라, 다른 지역에서 학습된 multi-basin representation이 DRBC에 일반화되는지를 평가한다.

3.3 Basin Split과 Subset300 Training Design

Training pool은 outlet이 DRBC 밖에 있고 DRBC polygon overlap이 0.1 이하인 quality-pass non-DRBC basin으로 구성하였다(outlet_in_drbc == False AND overlap_ratio ≤ 0.1, quality gate 통과 → 1,923개). 제 5장 논의

5.1 Output Design이 Peak Underestimation에 미치는 영향

결과는 본 연구의 핵심 가설을 지지한다. 같은 backbone을 유지해도 head를 deterministic point estimate에서 quantile output으로 바꾸면 upper-tail peak underestimation이 크게 줄었다. 특히 q99는 Q99 event scope에서 α를 거의 0에 가깝게 낮추고(0.018), Q99 threshold recall을 0.583까지 끌어올렸다.

이 결과는 extreme peak 문제를 해결하기 위해 항상 더 복잡한 backbone이나 physics-guided core가 먼저 필요한 것은 아니라는 점을 시사한다. Output design의 변경만으로도 의미 있는 개선이 가능하다.

5.2 Central Prediction과 Upper-tail Output의 역할 분리

q50은 central hydrograph를 담당하고, q90/q95/q99는 점점 보수적인 decision output으로 읽어야 한다. q50이 high-flow에서 under-bias를 보이는 것은 skewed streamflow distribution에서 conditional mean과 conditional median이 다르기 때문이며, upper-tail output이 필요한 이유이기도 하다.

따라서 Model 2를 평가할 때 q50 하나만 Model 1과 비교하면 probabilistic head의 핵심 장점을 놓치게 된다. 올바른 비교 체계는 "q50(중앙 추정값) + q90/q95/q99(상위 꼬리 결정 기준)"을 다층 framework로 보는 것이다.

권장 해석 체계: Model 2 = q50(central prediction) + q90/q95/q99(upper-tail decision outputs). q50은 전통적 성능 지표(NSE, KGE)로 평가하고, upper quantile은 recall–cost trade-off로 평가한다. 이 둘을 하나의 지표로 통합하면 두 역할 모두를 정확히 평가할 수 없다.

5.3 운영적 Trade-off

q99는 peak underestimation을 줄이지만 false-positive cost도 증가시킨다. 이 결과는 q99를 "항상 최선의 forecast"라고 주장하기보다, risk tolerance가 높은 상황에서 사용할 수 있는 conservative alert level로 해석해야 함을 의미한다.

실제 홍수 경보에서는 q90/q95/q99 중 어느 output을 사용할지는 missed peak cost와 false alarm cost의 상대적 중요도에 따라 달라진다. 예를 들어, 댐 운영이나 긴급 대피 발령과 같이 false negative(놓친 홍수)의 비용이 압도적으로 큰 경우에는 q99가 적합할 수 있지만, 잦은 오경보가 신뢰도 손상으로 이어지는 상황에서는 q90이나 q95가 더 균형 잡힌 선택일 수 있다.

5.4 한계 및 향후 연구

한계 1 — 확률론적 보정 부족: q99의 empirical coverage(0.787)가 nominal(0.99)에 미치지 못하므로, 완전한 calibration을 주장할 수 없다. Quantile Crossing Penalty(QCP), quantile recalibration, 또는 extreme value 통계적 사후 처리를 통한 개선이 필요하다.

한계 2 — Lower quantile 부재: 현재 quantile set은 q50/q90/q95/q99만 포함하므로 양방향 uncertainty evaluation(prediction interval, Winkler score)을 수행하지 않았다. Lower quantile을 포함한 full interval forecast가 후속 연구에서 필요하다.

한계 3 — Flash Flood의 잔존 한계: Flash Flood category에서는 q99에서도 α = 0.42의 residual under-deficit이 남았다. 이는 hourly forcing, basin response speed, routing/timing representation의 한계와 관련될 수 있다.

한계 4 — 단일 지역 검증: 현재 분석은 DRBC 85개 유역에 한정되므로, 산악 유역·건조 지역·대규모 유역 등 다른 지리적 조건에서의 일반화 가능성을 검증하지 않았다.

향후 연구 방향:

  • Lower quantile 포함 full interval forecast 및 양방향 calibration 평가
  • QCP 손실, quantile recalibration, 극한값 사후 처리 도입
  • Flash Flood timing 오차 완화: 더 높은 해상도 forcing 또는 routing 보완
  • Physics-guided conceptual core와의 hybrid 구조 탐색(후속 확장)
  • 비용-편익 정량화: 오경보와 미포착 사건의 사회경제적 비용을 통한 최적 τ 선택 가이드라인

제 6장 결론

본 연구는 CAMELSH hourly dataset과 DRBC regional holdout 조건에서 deterministic multi-basin LSTM(Model 1)과 probabilistic quantile LSTM(Model 2)을 비교하였다. 실험 설계는 backbone, 입력, basin split, temporal split, seed를 고정하고 output head와 loss function만 바꾼 공정한 비교 구조를 사용하였다.

결과적으로 네 가지 핵심 결론을 도출하였다.

  1. 다층 결정 산출값 체계의 유용성: Model 2 q50~q99 불확실성 밴드는 "더 정확한 단일 예측"이 아니라, 사용자가 위험 회피 선호도에 따라 τ를 선택할 수 있는 의사결정 지원 도구로 기능한다. q50은 central prediction 성능을 유지하고(NSE +0.149), q99는 Q99 event에서 peak underestimation을 0.018 수준까지 줄이며 recall을 0.583까지 향상시킨다.
  2. 상충 관계의 명시성: τ 증가에 따라 peak under-deficit은 감소하지만, false alarm rate은 23배 증가한다. 과소 간격 감소(q50 23.7 → q99 0.87 cms)와 과대 간격 등장(q99에서 3.58 cms)이 동시에 발생하는 비대칭 상충 구조는 "τ가 클수록 항상 좋다"는 단순한 주장을 부정한다.
  3. 극한 사건의 완전 포착 불가능성: 전체 사건 기준(event-pooled)으로 Q99 사건 첨두의 약 43%, NOAA 확인 홍수 첨두의 약 57%가 q99를 초과한다. 단일 또는 다층 신경망 기반 예측만으로는 모든 극한 첨두를 완벽히 보호할 수 없으며, 추가적 물리 기반 제약 또는 사후 조정이 필요할 수 있다.
  4. Output design의 중요성: 동일한 LSTM backbone에 probabilistic quantile head만 추가해도 flood peak protection 성능을 의미 있게 개선할 수 있다. Extreme peak 문제를 해결하기 위해 항상 더 복잡한 backbone이나 physics-guided core가 먼저 필요하지 않을 수 있다.
최종 결론: Probabilistic quantile head는 deterministic LSTM의 extreme flood peak underestimation을 줄이는 효과적인 output design이며, q90/q95/q99는 calibration claim이 아니라 recall–cost trade-off를 조절하는 upper-tail decision outputs로 해석해야 한다.
