수문학 전공 학부생 대상 설명 자료

LSTM 기반 극한 홍수 첨두 과소추정
진단 분석 — RQ-0 / RQ-1 / RQ-2 / RQ-3

Multi-basin LSTM 홍수 예측 모델이 극한 첨두유량을 얼마나 놓치는지, 어떤 유역에서 더 많이 놓치는지, 그리고 확률 예측(quantile 출력)이 이 문제를 얼마나 개선하는지를 단계별로 분석한다.

평가 유역: DRBC 관측 시험 85개 시험기간: 2014–2016 seed: 111 / 222 / 444 Q99 초과 사건: 926건 / 82개 유역
왜 이 연구인가

LSTM(Long Short-Term Memory)은 시계열 입력에서 강우-유출 관계를 학습하는 딥러닝 모델이다. 유역별 복잡한 비선형 특성을 잘 잡아 최근 수문 예측에 널리 쓰인다. 그러나 극한 홍수 첨두에서는 체계적으로 과소추정하는 경향이 있다.

이유는 단순하다. 홍수 첨두는 드문 사건이라 학습 데이터 안에서 비중이 작고, NSE(Nash-Sutcliffe Efficiency) 같은 손실 함수는 평균 오차를 최소화하는 방향으로 모델을 훈련시키기 때문이다.

⚠
핵심 문제: 홍수 경보·방재 관점에서 첨두를 낮게 예측하면 대피 기준을 충족 못 하거나, 제방·댐 운영에 잘못된 여유를 줄 수 있다. "평균적으로 잘 맞는" 모델이 홍수 현장에서는 위험할 수 있다.
비교 대상: 두 모델
Model 1
Deterministic LSTM
NSE 손실로 학습. 시점마다 단일 예측값 하나를 출력한다. 전통적인 방식으로 "가장 그럴 법한 유량"을 예측.
Model 2
Probabilistic Quantile LSTM
Pinball loss로 학습. 시점마다 q50 / q90 / q95 / q99 네 개 예측선을 동시에 출력한다. 관측값이 각 선 아래에 들어올 확률 수준을 직접 훈련.
ℹ
band vs point 비대칭: Model 2의 q99는 "넓게 잡은 상한선"이고 Model 1은 "점 예측"이다. 직접 비교는 구조가 달라 공평하지 않다. 이 분석에서는 Model 2 내부의 τ 진행(q50→q90→q95→q99)을 주비교 축으로 삼고, Model 1은 q50 기준선을 통해 간접 연결한다.
분석 체계 — RQ 사다리

세 연구 질문이 전제–결과 관계로 연결된다. RQ-0이 틀(frame)을 만들어야 RQ-1·RQ-2 결과 해석이 가능하다.

0
RQ-0 — 진단 틀
관측 위치 구간(obs_class)과 유역 특성의 관계
Model 2 예측 밴드(q50~q99) 안에서 관측 첨두가 어느 구간에 드는지를 다섯 단계로 정의하고, 유역 면적·대류성 강수 비율 같은 외부 특성이 그 위치를 예측하는 신호가 되는지 확인한다.
1
RQ-1 — 기준선
Model 2의 q50은 Model 1과 동등한가?
Pinball loss로 훈련한 Model 2의 중앙 예측선(q50)이 NSE 손실로 훈련한 Model 1과 중앙 성능에서 동등한지 확인한다. q50 ≈ Model 1이 성립해야 q50→q99 개선이 "기준 대비 개선"으로 읽힌다. 실제 결과: NSE +0.149 (Model 2 q50이 더 나음).
2
RQ-2 — 핵심 주장
τ 수준이 높아질수록 peak underestimation이 체계적으로 줄어드는가?
q50 → q90 → q95 → q99로 갈수록 과소추정이 단조 감소함을 세 지표(α, β, δ)로 정량화한다. 이것이 본 연구의 중심 주장이다.
3
RQ-3 — 비용
recall 개선의 대가로 어느 정도의 FAR·과대추정 비용이 따라오는가?
upper quantile을 쓸수록 놓치는 사건이 줄지만 오경보(false alarm)도 증가한다. FAR과 과대추정 크기를 τ별로 정량화하고, 운영 목적에 따른 τ 선택 기준을 제시한다.
RQ-0 — 관측 위치 구간(obs_class)과 신호 분석
관측 위치 구간(obs_class)이란?

Model 2가 q50 / q90 / q95 / q99 네 개 예측선을 출력하면, 실제 관측 첨두가 그 "사다리" 어디에 놓이는지를 다섯 구간으로 나눈 서수 변수다. 값이 클수록 모델이 관측을 더 심하게 낮게 예측한 것이다.

0
관측 ≤ q50  → 과대추정 쪽
1
q50 < 관측 ≤ q90  → 밴드 하부
2
q90 < 관측 ≤ q95  → 밴드 중상부
3
q95 < 관측 ≤ q99  → 밴드 최상부 근접
4
관측 > q99 → 과소추정 (연구 핵심)
★
obs_class = 4 (above_q99)는 q99 예측마저 관측 첨두를 못 잡은 경우다. 이것이 과소추정의 가장 심각한 형태이며, RQ-0은 이 사건이 어떤 유역에서 집중적으로 나타나는지를 찾는다.

obs_class와 상관관계가 높더라도 왜 높은지가 중요하다. 세 분류 중 독립 신호만 실제 예측력을 갖는다.

I. 독립 신호 ✓

실제 예측·진단에 쓸 수 있음.
C. 밴드 결합 ✗
예측 밴드 자체에서 파생된 값.
밴드가 넓으면 obs가 넘기 어려우므로 정의상 음의 상관.

L. 관측값 누수 △

gap selection — 유역 특성으로 어느 구간에 떨어질지 예측할 수 있는가?

Spearman 상관은 "평균적 연관성"을 보여 줄 뿐이다. 실제 gap selection 진단은 유역 특성 그룹별로 obs_class 0~4가 어떤 비율로 분포하는지를 직접 보는 것이다. 큰 유역(Q4)일수록 class 4(above_q99) 비율이 높다면, "이 유역은 홍수 첨두가 q99마저 초과할 가능성이 높다"고 사전 진단할 수 있다.

Q2 (n=285) 2.8% 9.8% 14.0% 33.0% 40.4%

gap selection 해석: 소형 유역(Q1)에서 above_q99 비율은 20.0%지만, 대형 유역(Q4)에서는 64.5%다(Q2 40%, Q3 58% 순차 증가). 면적만 알아도 "이 유역의 홍수 첨두가 q99를 초과할 사전 확률"을 세 배 이상 다르게 추정할 수 있다. 이것이 gap selection의 핵심 — 사건이 발생하기 전(또는 직후)에 obs_class 분포를 유역 특성으로 조건화하는 진단 틀이다.

하위 50% (낮은 대류성 비) 낮음 대규모 지속 강우 — 모델이 상대적으로 잘 따라감
상위 50% (높은 대류성 비) 높음 (NOAA r = +0.38) 단시간 대류성 폭우 — 모델 구조적 실패 집중

두 특성(면적 + 대류성 강수 비율)을 조합하면 "대형 유역 + 대류성 폭우" 조합이 above_q99 위험 구간으로 분류될 가능성이 가장 높다는 복합 진단이 가능하다.

RQ-1 — Model 2의 q50은 Model 1과 동등한가?

tradeoff — 놓치는 사건이 줄어드는 대가

q99으로 갈수록 recall이 늘지만 FAR(오경보율)도 함께 증가한다. 이것이 RQ-3에서 분석하는 cost 문제다.

지표 q50 → q99 변화 의미
δ recall (개선) 0.069 → 0.583 (+8.5×) Q99 초과 시각을 더 잘 커버
miss rate (개선) 93.1% → 41.7% (−51%p) 놓친 사건 절반 이상 회수
FAR (증가) +24× 증가 (RQ-3 결과) 과경보 시각도 함께 늘어남
⚠
recall 8×, FAR 24× — 비대칭 tradeoff다. q99을 "단일 예측"이 아닌 "upper envelope"로 읽어야 하며, 운영 목적(미감지 비용 vs 오경보 비용)에 따라 적합한 τ 수준을 선택해야 한다.
RQ-3 — FAR과 과대추정: 어떤 비용이 따라오는가
FAR(오경보율)이란?

FAR = P(q_τ > Q99_임계 | 실제 관측 < Q99_임계) — 실제로는 Q99 초과가 아닌 시각에 모델 예측이 Q99를 넘어버리는 비율이다. τ가 높을수록 예측선이 위로 올라가므로 이 오경보 시각 수도 늘어난다.

⚠
FAR 분모는 시험기간 전체의 99% 시각(Q99 비초과 시간)이다. 홍수가 드문 사건임을 반영해 절대값이 작아 보이지만, 배수 증가율은 recall보다 훨씬 가파르다.
recall × FAR 대비표 — τ 선택의 핵심
τ 수준 δ recall (중앙값) FAR (중앙값) 과대추정 크기 (중앙값) 특징
Model 1 (참고) 0.143 0.0018 1.80 점 예측 기준선
q50 0.069 0.00068 1.47 최소 오경보, 최소 커버
q90 0.280 0.0042 2.19 FAR 6× 증가, recall 4× 증가
q95 0.379 0.0063 2.29 균형점 후보 — recall 0.38, FAR 0.63%
q99 0.583 0.0164 3.44 FAR q50 대비 ×24, recall ×8.5

배수 기준: FAR ×24 폭증 vs recall ×8.5 — FAR이 더 가파르게 오른다.

절대값 기준: FAR 변화폭 +0.016 vs recall 변화폭 +0.51 — recall 이득이 절대 크기로는 훨씬 크다. Q99 홍수가 드문 사건이라 오경보 절대 시간 수가 적은 것이다.

과대추정 크기: q99에서 중앙 3.44 mm/hr 초과 — 유역 규모에 종속적이라 basin 간 절대 비교는 주의가 필요하다 (IQR 2.4~10.5로 넓다).

τ 선택 기준 — 운영 목적에 따라 다르다

τ 선택에는 정답이 없다. 아래 두 질문의 답에 따라 달라진다.

운영 목적 권장 τ 근거
홍수 미감지를 최대한 줄이고 싶다
(생명·재산 보호 최우선)		 q99 miss rate 41.7%, recall 58%. 오경보 증가를 감수하고 놓치는 사건 최소화.
recall과 FAR 균형이 필요하다
(대응 자원이 한정적)		 q95 recall 0.38 / FAR 0.63% — 두 지표 사이 균형점. q99보다 과대추정 크기도 작다.
오경보 비용을 최소화해야 한다
(경보 신뢰도 유지 필요)		 q90 FAR 0.42%로 작으면서 recall q50 대비 4× 개선.
★
q99를 "단일 정답"이 아닌 upper envelope로: q50~q99 밴드 전체를 보면 관측 첨두가 밴드 안에 드는지(α ≈ 0)와 그 대가로 밴드가 얼마나 넓어지는지(FAR 증가)를 함께 읽는 것이 올바른 해석이다.
통합 해석 — 네 연구 질문이 연결하는 이야기

RQ-0이 보여 준 것: 유역 면적이 크고 대류성 폭우가 집중되는 유역에서 관측 첨두가 q99마저 초과하는 비율이 높다(면적 Q1 소형 20% → Q4 대형 65%). 모델 한계는 무작위가 아니라 유역 구조·강우 성격에 따라 예측 가능하다.

RQ-1이 보여 준 것: Pinball loss 훈련이 중앙 예측 성능을 희생하지 않는다. q50 NSE +0.149로 Model 1보다 오히려 낫다. RQ-2의 q99 개선이 "단순히 보수적으로 높인 것"이 아니라 실제 학습 효과임을 뒷받침한다.

RQ-2가 보여 준 것: q50→q90→q95→q99 τ 진행에 따라 과소추정이 단조 감소한다. Q99 scope 기준 α 36× 개선, miss rate −51%p, δ recall 8.5× 증가. 방향은 NOAA 공식 확인 홍수에서도 동일하게 재현된다.

RQ-3이 보여 준 것: recall ×8.5의 대가로 FAR ×24 증가. 절대 변화폭은 recall(+0.51)이 FAR(+0.016)보다 훨씬 크다. q95가 recall 0.38 / FAR 0.63%로 균형점 후보이며, 운영 목적(미감지 비용 vs 오경보 비용)에 따라 τ를 선택한다.

★
결론: Quantile LSTM의 upper quantile 출력은 극한 홍수 첨두 과소추정을 대폭 줄인다. 어떤 τ를 쓸지는 운영 환경의 비용 구조에 달려 있으며, 대류성·대유역 조건에서 한계가 집중됨을 함께 인식해야 한다.
