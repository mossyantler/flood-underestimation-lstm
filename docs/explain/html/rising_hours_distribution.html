⚠️
above_q99 중앙값(12h) ≈ 전체 중앙값(11h). 상승 시간만으로는 "위험한 홍수"를 구분할 수 없습니다. 오히려 below_q50(과예측 구간)에서 상승 시간이 16.5h로 가장 깁니다 — 천천히 올라오는 홍수일수록 모델이 오히려 과예측하는 경향.
왜 rise_slope는 r=0.359인데 rising_hours는 구분력이 낮은가?
12시간 동안 10→200 cfs로 올라온 홍수(slope=15.8 cfs/h)와 12시간 동안 10→30 cfs로 올라온 홍수(slope=1.7 cfs/h)는 rising_hours가 동일합니다. 하지만 첫 번째만 above_q99가 됩니다. 중요한 것은 시간 자체가 아니라 단위 시간당 얼마나 급격하게 올라오는지(slope)입니다.

6. 종합 해석
발견해석시사점
75%가 24h 이내 상승 CAMELS 유역 대부분이 단기 강수 반응형 6~12h 창이 실시간 모니터링 핵심 윈도우
above_q99 중앙값 12h ≈ 전체 11h 시간 자체로는 위험 구분 불가 rising_hours 단독 사용 비추천
below_q50 중앙값 16.5h (가장 김) 천천히 올라오는 홍수 → 모델 과예측 장기 상승 = 과예측 패턴 연구 가치 있음
72–200h 구간 above_q99 = 61.5% 중간 길이 상승 사건이 가장 위험 (표본 소량) 주의: n=39, 불안정. 추가 검증 필요
200h+ above_q99 = 32.8% (낮음) snowmelt형 완만 상승 → 상대적으로 예측 용이 장기 사건 분류 분리 분석 고려
rise_slope r=+0.359 달성 시간이 아니라 속도(slope)가 예측력 있음 실시간 모니터링에서 slope 계산이 핵심
